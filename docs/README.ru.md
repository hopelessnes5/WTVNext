# WTVNext — Windows Texture Viewer Next Gen

Нативные утилиты для прямой работы с текстурами: просмотрщик с аутентичным классическим
интерфейсом и shell-расширение, показывающее превью `.dds` прямо в Проводнике.

## Возможности

### WTVNextApp.exe — просмотрщик текстур

Полноценный современный аналог Windows Texture Viewer с аутентичным классическим интерфейсом:

- **Движок** — аппаратный DirectX 11 с нативной поддержкой BC1–BC7, BC6H (HDR),
  DXT1–DXT5, кубических карт, а также TGA, PNG, JPG, HDR.
- **Адаптивность** — автоматическое центрирование и масштабирование текстур любого
  разрешения (вплоть до 4K/8K) при изменении размера окна или развороте на весь экран.
- **Управление:**
  - зум к курсору колёсиком мыши, панорама с зажатой левой кнопкой мыши;
  - уровни Mip — `↑` / `↓` (а также `PgUp` / `PgDn`);
  - предыдущий / следующий файл в папке — `←` / `→` (а также `Space` / `Backspace`);
  - каналы `1`–`6` (RGBA, RGB, Alpha, Red, Green, Blue), `A` — переключение RGBA,
    `N` — восстановление Z-компоненты карт нормалей;
  - `F` — вписать в окно, `Home` / `0` — зум 100 %.

### WTVNext.dll — превью в Проводнике

64-битный Shell Thumbnail Provider для Проводника Windows:

- превью `.dds` (BC1–BC7, BC6H/HDR) отображаются прямо в Проводнике;
- **Интеграция** — регистрация и снятие расширения выполняются в один клик через меню
  **Help → Register Shell Extension (Thumbnails)** в просмотрщике, с автоматическим
  запросом прав администратора и быстрым перезапуском `explorer.exe` для немедленного эффекта.

## Состав репозитория

| Путь | Содержимое |
|---|---|
| `WTVNext/` | COM shell-extension DLL (`WTVNext.dll`) — провайдер эскизов `.dds` |
| `WTVNextApp/` | Win32/D3D11 просмотрщик (`WTVNextApp.exe`) |
| `external/DirectXTex/` | единственная vendored-копия DirectXTex + предсобранные `.lib` |
| `docs/` | план рефакторинга, русская версия README и сопутствующие документы |

## Сборка

Требуется Visual Studio 2022 (toolset v143) и Windows 10/11 SDK.

1. Открыть `WTVNext.sln`.
2. Собрать конфигурацию **Release | x64** (остальные конфигурации пока не заведены —
   см. этап 1 в [плане рефакторинга](deepseek-WTVNext-refactoring-plan.md)).
3. Артефакты: `x64\Release\WTVNext.dll` и `x64\Release\WTVNextApp.exe`.

DirectXTex линкуется предсобранными `.lib` из `external/DirectXTex`; исходники и проекты
находятся там же, при необходимости их можно пересобрать.

## Регистрация превью `.dds`

Запустить `WTVNextApp.exe` → **Help → Register Shell Extension (Thumbnails)**
(требует прав администратора, вызывает `regsvr32`). Там же — снятие регистрации.
